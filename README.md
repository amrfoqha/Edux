# EduX

EduX is a team-based MERN stack web application that enables students to share and exchange academic resources.

## Project Structure
client/   → Frontend (React)  
server/   → Backend (Node.js, Express)

## Features
- User Authentication (Login & Register)
- Share and upload academic resources
- Browse and search materials
- Team-based development

## Tech Stack
### Frontend
- React
- Tailwind CSS

### Backend
- Node.js
- Express
- MongoDB
- JWT Authentication
